# ADR-0001: 不做 repo map

- 状态：被采纳
- 日期：2026-10-06

## 背景

aider 原版用 tree-sitter 生成仓库大纲（签名 + 关键引用）喂给 LLM，是其区别于朴素「把文件全塞给模型」的核心能力，但也是移植工作量最大、最需要对标的单件。

## 决策

**本项目明确不做 repo map**（不是延后，而是砍掉）。

代码上下文由以下来源提供：
- 仓库文件树；
- grep / 文件检索；
- 由用户或 Claude Code 在任务中显式指定相关文件。

## 后果

- 优点：显著降低移植工作量与复杂度，MVP 更快闭环，符合极轻量目标。
- 代价：跨文件/大型代码库的全局关联理解能力相对 a 原版下降，依赖编排方（Claude Code）或用户指定上下文。
- 若未来需要，可单独立项续做；不影响已定编辑格式、LLM 循环与 git 集成。
